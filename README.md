# 🚀 SEVEN — Modern Full-Stack Blog & Media Platform

A high-performance, full-stack social media & blogging platform built with **Python (Flask)** and modern frontend design practices. Features user authentication, rich media posts (video & images), interactive engagement systems, and responsive dark-mode UI.

🚀 **Live Demo:** [https://flask-blog-v2.onrender.com](https://flask-blog-v2.onrender.com)

---

## 🌟 Key Features

* 🔐 **User Authentication & Authorization:** Secure login, registration, and session management.
* 📹 **Rich Media Support:** Native video embedding, image uploads, and post rendering.
* 💬 **Interactive Social Features:** Post creation, like counters, comment threads, and shareable permalinks.
* 📱 **Modern UI/UX:** Dark-mode interface optimized for high engagement and seamless responsiveness across desktop and mobile devices.
* ☁️ **Cloud Deployment:** Production-ready deployment hosted on Render infrastructure.

---

## 🛠️ Tech Stack & Architecture

* **Backend:** Python 3, Flask (RESTful routing, Templating)
* **Database & ORM:** SQLAlchemy (Relational Data Modeling, User/Post relationships)
* **Frontend:** HTML5, CSS3 (Custom Dark Theme UI), JavaScript (DOM manipulation)
* **Hosting & Deployment:** Render Cloud Platform

## ✨ Features

* 🔐 **Authentication System:** Secure user registration, login, and session handling.
* ✍️ **Complete CRUD Operations:** Create, edit, update, and delete blog posts seamlessly.
* 🔗 **SEO-Friendly URLs:** Custom post slugs (`/post/your-title`) for clean and shareable links.
* 📊 **Admin Dashboard:** Centralized management interface for tracking and managing user content.
* 👤 **Author & Timestamp Tracking:** Dynamic post metadata showing creator details and publishing dates.
* 💾 **Database Integration:** Reliable data storage powered by SQLite (`instance/blog.db`) using ORM models.
* 🎨 **Modern Responsive UI:** Custom dark-mode theme built with Tailwind CSS for seamless viewing across desktop and mobile devices.
* 🚀 **Cloud Deployment:** Production-ready setup configured for seamless hosting on Render.
